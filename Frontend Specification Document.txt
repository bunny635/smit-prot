Version: 1.0Product: The Digital MuseumFrontend: Next.js + React + TypeScriptVisual direction: Futuristic digital museum / premium interactive portfolioPrimary principle: The museum creates the atmosphere; the portfolio delivers the information.

54. Sign Out
Use:
supabase.auth.signOut({
  scope: 'local'
})
For this product, local is generally preferable so logging out on one browser doesn't unexpectedly terminate every other admin session. Supabase's current JavaScript documentation notes that the default scope is global and explains the local/others alternatives. 

55. Getting the Current User
For trusted server-side identity checks, use Supabase's server-side session/user APIs rather than trusting client-provided user data.
This matters because Supabase distinguishes local session data from verified user information.
