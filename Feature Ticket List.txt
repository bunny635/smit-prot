AI CODING AGENT RULES
Every coding agent working on these tickets should follow these product rules from the PRD:
Do not rewrite unrelated code.
Do not add features that are not part of the current ticket.
Do not make Three.js a dependency for basic portfolio functionality.
Do not sacrifice accessibility for visual effects.
Do not sacrifice performance for visual effects.
Do not invent portfolio achievements, project results, or timeline milestones.
Use real project content where available and clearly identify placeholders during development.
Every interactive feature must have a usable keyboard/mobile equivalent.
Every animation must have a product reason.
Every ticket must be verified before being marked complete.
These rules directly preserve the PRD's central principle: the museum is the presentation layer, while the underlying product remains a high-quality, highly usable portfolio.
